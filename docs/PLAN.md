# O plano do mês

O Tostão regista o que *aconteceu*. O plano diz o que *devia* acontecer: o que entra, o que é para sair e o que se põe de lado. É a versão na aplicação da folha de cálculo que muita gente tem em casa, e fica em **Plano**, no menu.

## Linhas do plano

Cada linha tem:

| Campo | Para quê |
|---|---|
| **Tipo** | Receita, despesa ou poupança. |
| **Montante** | O valor previsto por mês. |
| **De quem** | Comum (a casa), ou uma pessoa. |
| **Previsibilidade** (só despesas) | **Fixa** (verde: valor combinado), **variável obrigatória** (amarelo: depende do consumo mas tem de se pagar) ou **opcional** (sem cor). |
| **Grupo** | Uma etiqueta livre para somar coisas (por exemplo, "Animais" ou "Subscrições"). Uma linha de cada pessoa ou da casa pode ter o seu. |
| **Categoria ligada** | A categoria dos movimentos reais com que a linha se compara. |
| **Meses** | Vazio = todos os meses. Marca só alguns para linhas que não são mensais (um subsídio de Natal, um seguro anual). |

## O que a página mostra

- **Receita prevista, despesa prevista, o que se põe de lado e o que sobra.** A sobra é calculada para o mês que estás a ver, por isso os meses com subsídio têm mais sobra.
- **Por pessoa:** as linhas agrupadas, com o total, a percentagem do rendimento total da casa e os subtotais por tipo. Em cada pessoa aparece também o total *com uma parte igual do que é comum*, que é o que cada um suporta de facto.
- **Por grupo:** quanto custa, por exemplo, o animal, por mês.
- **Plano contra o que aconteceu:** para cada categoria ligada, quanto se gastou este mês contra o previsto (a barra fica amarela perto do limite e vermelha acima). Só conta despesa; as transferências nunca contam.

## Subsídios

Se metade do subsídio já vem diluída no ordenado e a outra metade é paga de uma vez, o ordenado mensal é uma linha de receita, e cada pagamento único é outra linha com o mês marcado (por exemplo, o de Natal em novembro). Assim a sobra de cada mês é a verdadeira.

## Relação com o resto

- **Orçamentos por categoria** (em Categorias) continuam a existir e avisam no painel. O plano é mais fino: tem pessoas, tipos e grupos.
- **Movimentos recorrentes** criam movimentos reais sozinhos; o plano só descreve o que se espera.
- **Transferências para poupança ou investimento** são movimentos que não contam como despesa. No plano, são linhas do tipo poupança.
